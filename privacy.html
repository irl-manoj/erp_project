Privacy Policy

Applies to: this demonstration website only. Last updated: 27 September 2026.
Read this first: this is an academic student project, not an official BIT Mesra system. It has no backend server. Everything you see is simulated demo data. Do not enter real personal information, passwords you actually use, or official academic records anywhere on this site.

1. What this site is

The MCA Academic Dashboard is a frontend-only demonstration of a student/faculty academic portal (attendance, quiz marks, internals, end-semester marks, assignments, SGPA/CGPA). All names, roll numbers, marks, attendance figures and notices are fictitious data created for the demo. Any resemblance to real persons is coincidental.

2. Data collected: none

This site does not operate a server that receives or stores your data. There is no sign-up, no tracking script, no analytics, no advertising network, and no email collection. Login accepts any input by design so that the demo can show role switching; nothing you type at login is transmitted anywhere.

3. Data stored in your browser

To demonstrate persistence (for example, a teacher entry appearing on the student view after reload), the demo saves two keys in your browser's localStorage:

  • mca_current_user - which demo profile is signed in (name, role, roll number from the mock data set)
  • mca_db_v2 - the simulated records you edited during the demo (attendance, marks, assignments)

This data never leaves your device. Clearing your browser site data removes it completely, and the demo regenerates its default data on the next visit.

4. Third-party resources

The pages load open-source libraries and fonts from public CDNs (Bootstrap, Chart.js, Font Awesome via jsDelivr; Google Fonts). A request to these providers is made by your browser when a page loads, and standard web requests include technical details such as your IP address and user agent. The library code is not modified and does not collect information on our behalf. If you would rather avoid this, the files can be self-hosted with no functional changes.

5. Children and sensitive data

The demo is a classroom project and is not directed at children. Because it stores data only in your own browser, it does not process anyone else's information.

6. Your choices

  • Remove all demo data at any time: open DevTools, then Application (or Storage), and clear Local Storage for this site.
  • Use the site in a private/incognito window so nothing persists after you close it.

7. If this project is ever hosted for real users

The roadmap for this project includes connecting a real backend with proper authentication. If that ever happens, this policy will be rewritten before launch to cover account data, password hashing, session handling, data retention, and applicable Indian law (including the Digital Personal Data Protection Act, 2023). Until then, "no server, no collection" remains the accurate statement.
